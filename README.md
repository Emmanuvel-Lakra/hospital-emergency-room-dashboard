## 📊 hospital-emergency-room-dashboard — Excel Project

Interactive Microsoft Excel dashboard for analyzing hospital emergency room activity, patient attendance, waiting time, satisfaction, admissions, demographics, and department referrals.

### Download the Dashboard

[**Download the Excel Dashboard (.xlsx)**](https://github.com/Emmanuvel-Lakra/hospital-emergency-room-dashboard/raw/refs/heads/main/project%201.xlsx)

### How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. If prompted, click **Enable Editing**.
4. Use the available filters and slicers to explore the sales data.

**Note:** Interactive features may not work in GitHub's file preview. Open the downloaded workbook in a compatible desktop version of Microsoft Excel.
